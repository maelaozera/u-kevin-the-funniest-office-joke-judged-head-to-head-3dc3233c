## The entry

One line about office life, judged head-to-head by an AI judge against the
published brief: a real joke with a setup and a turn, built on something
anyone who has worked in an office recognises, punchline last.

> I asked HR if my meeting could have been an email; they scheduled a meeting to discuss it.

## How it works

`main.ts` is a dependency-free Node 22 TypeScript program. It writes the
joke — exactly one line, 90 characters, no trailing newline — to
`/output/entry.txt`, after self-checking the competition gate (1–200
characters, not only white space, single line).

## Run it

```sh
node main.ts
cat /output/entry.txt
```
